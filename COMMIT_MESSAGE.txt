feat: Add comprehensive debug window with performance monitoring and error tracking

## Summary

Implemented a professional debug monitoring system with DOS-themed UI that provides
real-time error tracking, performance monitoring, and operation logging. The debug
window stays hidden by default and automatically appears when issues are detected,
maintaining the retro aesthetic while adding enterprise-grade debugging capabilities.

## Features Added

### Debug Window System (src/ui/debug_window.py)
- DOS-themed debug window with black background and bright green text
- Color-coded logging system:
  * Green text for informational messages
  * Yellow text for warnings
  * Red text for errors
- Auto-show functionality triggered by errors, warnings, or performance issues
- Performance monitoring thread that detects operations exceeding 30 seconds
- Operation timing and tracking with start/end timestamps
- Global exception handler that catches and logs unhandled exceptions
- Real-time status label displaying error and warning counts
- Control buttons for clearing logs, hiding window, and toggling visibility
- Thread-safe logging with proper synchronization

### Main Application Integration (src/ui/main_window.py)
- Imported DebugWindow and DebugExceptionHandler classes
- Created debug window instance during application initialization
- Installed global exception handler to catch all unhandled exceptions
- Added keyboard shortcut (Ctrl+D) to toggle debug window visibility
- Instrumented all major operations with comprehensive logging:
  * load_file() - Logs file dialog, selection, cancellation, and errors
  * analyze_mesh() - Logs analysis start, results, severity warnings, and errors
  * repair_mesh() - Logs repair progress, validation results, warnings, and errors
  * export_files() - Logs directory selection, format-specific exports, and errors
- Wrapped all operations with start_operation() and end_operation() calls
- Added try/except blocks with proper error logging and re-raising

## Technical Details

### Architecture
- DebugWindow class manages UI and logging functionality
- DebugExceptionHandler class provides global exception catching
- Performance monitoring runs in separate daemon thread
- Operation tracking uses dictionary to store start times
- Thread-safe logging using Tkinter's after() method

### Performance
- Minimal overhead from logging operations
- Background thread for non-blocking performance monitoring
- Conditional window display reduces memory usage
- Efficient text widget with automatic scrolling

### User Experience
- Hidden by default to avoid clutter
- Automatic appearance on issues for immediate visibility
- Simple Ctrl+D toggle for manual control
- Clear visual hierarchy with color-coded messages
- Consistent DOS theme throughout
