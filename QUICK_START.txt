TROUBLESHOOTING
================================================================================

Issue: Installation fails
Fix: See INSTALLATION_GUIDE.txt

Issue: GUI won't open
Fix: Make sure tkinter is installed (included with Python)

Issue: Python 3.14 compatibility
Fix: Install Python 3.12 alongside, or just install trimesh
