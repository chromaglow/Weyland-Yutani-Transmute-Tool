🎯 WHAT THIS TOOL DOES
================================================================================

Fixes STL files that look solid but slice as hollow:

  1. Load your STL file
  2. Analyze for defects
  3. Repair automatically
  4. Export fixed STL (and optionally STEP for SolidWorks)
