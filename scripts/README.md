# Utility Scripts

This directory contains utility scripts for the Weyland-Yutani Transmute Tool.

## Available Scripts

### Installation & Running
- **install_minimal.bat** - Install minimal dependencies
- **run_app.bat** - Run the application

### Development Tools
- **check_one_file.py** - Check a single file
- **test_syntax.py** - Test Python syntax
- **organize_project.py** - Organize project structure

## Usage

### Run the Application
```batch
scripts\run_app.bat
```

### Install Dependencies
```batch
scripts\install_minimal.bat
```

### Organize Project
```batch
python scripts\organize_project.py
```

## Notes

- Run scripts from the project root directory
- Some scripts may require Python to be installed
- Check individual script headers for specific requirements
