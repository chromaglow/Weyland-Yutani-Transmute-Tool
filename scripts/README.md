# Utility Scripts

This directory contains utility scripts for the Weyland-Yutani Transmute Tool.

## Available Scripts

### Installation & Running
- **install_minimal.bat** - Install complete dependencies (trimesh + scipy)
- **run_app.bat** - Run the application

### Maintenance & Organization
- **organize_project.py** - Organize project files into proper directories
- **cleanup_update.bat** - Comprehensive cleanup and update script (in root)
- **test_freecad.py** - Test FreeCAD detection and troubleshoot integration issues

## Usage

### Run the Application
```batch
scripts\run_app.bat
```

### Install Dependencies
```batch
scripts\install_minimal.bat
```

### Organize Project
```batch
python scripts\organize_project.py
```

## Notes

- Run scripts from the project root directory
- Some scripts may require Python to be installed
- Check individual script headers for specific requirements
